# 医療の系譜

職場の健康診断（特殊健診）の制度・歴史・条文を図表でまとめた学習用サイトです。

| ページ | ファイル | 内容 |
|---|---|---|
| 医療 | `index.html` | 特殊健診の制度・歴史・条文、特定業務従事者健診の業務と健診項目、用語集 |
| 健診ガイド | `kenshin-guide.html` | 一般健診・特定業務従事者健診・特殊健診の比較、制度史、安衛法・安衛則、有機則・特化則・じん肺法・騒音ガイドライン、実務の判断フロー（印刷・PDF保存可） |
| 特殊健診 | `exam.html?id=ex-organic` など | 11種類の健診ごとの専用ページ |

共通のスタイルは `site.css`、特殊健診のデータは `data/medicine-exams.js` にあります。`index.html` をブラウザで開くか、GitHub Pages で公開して閲覧します。

## 医療（index.html）

- **特殊健診**：一般健診との違い、2つの制度が並行して発展した流れ（図）、制度年表（裏付けの確認状況つき）、種類一覧、実施の流れ（図）、頻度緩和の条件、特定業務従事者健診の対象者が少なく見える理由（考察）
- **特定業務健診**：安衛則第13条の14業務と昭和23年通達の解説、特殊健診の項目が加わる業務、年2回の健診で省略できる項目（出典：和歌山産業保健総合支援センター、2020年5月）
- **規則と条文**：法令の階層、健診の根拠条文、有機則・特化則・じん肺法・騒音ガイドラインの解説（e-Gov と厚労省資料へのリンク）
- **用語集**

学習用の一般情報です。健診の実施判断は産業医や労働基準監督署に確認してください。
